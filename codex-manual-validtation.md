# Codex Manual Validation Guide

## Purpose
- Provide a deterministic manual test procedure to validate FreightOS behavior in app.
- Ensure key scenarios and interactions are correct for the POC demo.

## Environment Setup
1. Use Node/Bun environment consistent with project dependencies.
2. Install dependencies using `bun install`.
3. Run app with `bun run dev`.
4. Open app in browser at `http://localhost:3000`.
5. Set viewport to 390 x 844 (iPhone 14).
6. Keep devtools console visible for unexpected errors.

## Global Pass/Fail Rules
- Pass: behavior matches expected result with no console errors.
- Fail: mismatch in UI, state, route, or deterministic scenario outcome.
- Blocker: crash, frozen UI, or corrupted cross-screen state.

## Validation Matrix Format
- Step ID
- Preconditions
- Action
- Expected Result
- Notes
